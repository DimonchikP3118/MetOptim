## Запуски программ и создание ими файлов и папок:
task.py - папка results:
- bellman_values.csv — значения Беллмана.
- bellman_actions.csv — оценки действий.
- strategy.csv — оптимальная стратегия.

test_task.py - папка test_results_required:
- checks.csv — таблица проверок.
- checks.json — данные проверок.

measure.py - папка results:
- bellman_values.csv — значения Беллмана.
- bellman_actions.csv — оценки действий.
- strategy.csv — оптимальная стратегия.
- measurements.json — замеры времени и памяти.
